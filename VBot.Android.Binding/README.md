# VBot Android Binding Library (.NET 9.0)

Thư viện Binding C# cho VBot Phone Android Native SDK (`VBotPhoneSDKAndroid-Public`).

## Cách tích hợp file AAR:
1. Build AAR từ repo `VBotPhone-Android-Public` hoặc tải `vbot-phone-sdk-android-1.1.2.aar`.
2. Copy file AAR vào thư mục `Jars/`.
3. Kiểm tra các class trong `Transforms/Metadata.xml` nếu có lỗi conflict type hoặc namespace.
